# Daily Wins Journal

A simple personal journaling app for tracking daily little wins and positive
moments, planning tomorrow's to-do list, and writing down 5 things you're
thankful for plus 5 affirmations.

Entries are saved per day in your browser's local storage — nothing leaves
your device.

## Running locally

```bash
npm install
npm run dev
```

Open the printed local URL in your browser. Use the arrows at the top to
navigate between days; each day has its own wins, to-do list, gratitude,
and affirmations.
